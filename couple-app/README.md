# 🐸 개굴씨 부부연구소

부부 둘이 함께 쓰는 관계 개선 앱. 매일 30분씩 30일 과정을 개굴씨와 함께 진행하고,
사주팔자 · 사랑의 언어로 서로를 이해하고, 하지 말아야 할 것을 함께 약속합니다.

> 이 앱은 전문 부부상담을 대신하지 않습니다. 몸을 다치거나 위협을 느끼는 상황이 있다면
> 앱보다 먼저 112 / 여성긴급전화 1366(남성도 이용 가능)에 도움을 요청하세요.

## v2.0 새로워진 점

- 🎙️ **아나운서 음성 안내**: 폰의 TTS 엔진에서 한국어 **여성 목소리**를 자동 선택(차분한 속도 0.92). 30분 과정 단계 자동 낭독, 개굴 타임 호흡 안내, 🔊 버튼으로 모든 핵심 문장 듣기. 도구 → 음성 안내에서 목소리·속도·높이 조절
- 🌱 **개선 로드맵**: 0단계 안전 → 멈추기 → 듣기 → 탓 대신 나 → 사랑 채우기 → 유지. 단계별 목표·이유·할 일 체크·확인 기준, 상담 내용 기반 2~4주 판단 기준
- 📊 **주간 점검**: 두 사람의 규칙 위반, 듣기, 사랑 표현, 편지, 마음 온도를 숫자로. 감정 통장(좋은 일 : 아픈 일, 목표 5:1)과 상황별 안내
- 💗 **사랑 채우기**: 상대의 사랑의 언어에 맞춘 매일 사랑 미션, 사랑 우체통(빠른 문장, 💗 마음 받기, 편지 낭독), 칭찬 한 줄 바로 보내기
- 🎨 장미빛 디자인으로 새 단장 (밝은/어두운 테마)

## APK 받기

📱 **폰에서 바로 받기:** https://github.com/merry240820-prog/Ai-skill-twin/releases/download/couple-latest/gaegul-couple.apk

푸시할 때마다 자동으로 새로 빌드되어 같은 주소로 갱신됩니다.

### 빌드 방식 (GitHub Actions)

`couple-app/` 아래가 바뀌어 푸시되면 **Actions → 개굴씨 APK 빌드**가 자동 실행됩니다.

1. GitHub 저장소 → Actions → 최근 실행 → 아래 Artifacts의 `gaegul-couple-apk` 다운로드(zip 안에 apk)
2. 폰으로 옮겨 설치 (설정에서 "출처를 알 수 없는 앱 설치" 허용)
3. `couple-v1.0` 같은 태그를 푸시하면 Releases 페이지에도 apk가 올라갑니다 → 폰에서 바로 받기 편함

### 업데이트해도 기록이 지워지지 않게 (권장)

서명 키가 바뀌면 안드로이드는 "덮어쓰기 설치"를 거부해서 앱을 지웠다 다시 깔아야 하고, 그러면 기록이 사라집니다.
debug 빌드는 실행마다 키가 달라지므로, 오래 쓸 거라면 **고정 키를 한 번 만들어 시크릿에 등록**하세요.

```bash
keytool -genkeypair -v -keystore gaegul.jks -alias gaegul -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 gaegul.jks   # 출력값을 복사
```

저장소 Settings → Secrets and variables → Actions 에 등록:

| 이름 | 값 |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | 위 base64 출력 |
| `ANDROID_KEYSTORE_PASSWORD` | 키스토어 비밀번호 |
| `ANDROID_KEY_ALIAS` | `gaegul` |
| `ANDROID_KEY_PASSWORD` | 키 비밀번호 |

등록하면 이후 빌드는 같은 키로 서명된 release APK가 되어 업데이트 설치가 됩니다. `gaegul.jks`는 저장소에 올리지 말고 따로 보관하세요.
업데이트 전에는 혹시 모르니 도구 → 동기화에서 기록 코드를 만들어 두세요.

## 로컬 개발

```bash
cd couple-app
npm run serve          # 브라우저에서 http://localhost:8080 (휴대폰 브라우저에서 홈 화면에 추가해도 동작)
npm ci && npm run android:init && npm run apk   # Android SDK가 있는 PC에서 직접 APK 빌드
```

```
couple-app/
├─ www/                  앱 본체 (HTML/CSS/JS, 의존성 없음)
│  ├─ js/saju.js         사주 계산 (절기=태양황경, 일주=JDN, 오호둔·오서둔, 진태양시 보정)
│  ├─ js/data.js         30일 과정 · 하지 않기 목록 · 사랑의 언어 문항 · 일간 해설
│  ├─ js/frog.js         개굴씨 캐릭터 SVG
│  └─ js/app.js          화면 · 저장 · 동기화
├─ assets/               아이콘 · 스플래시 원본
└─ capacitor.config.json
```

### 사주 계산 메모

- 연주는 입춘(태양황경 315°), 월주는 12절기 기준. 태양 위치는 천문식으로 계산(오차 약 15분 이내)
- 일주는 60갑자 일진(2024-01-01 = 갑자일로 검증), 23시 이후 출생은 다음 날 일주
- 진태양시 보정(-30분)은 옵션. 1948–1961, 1987–1988년 서머타임 기간 출생이면 만세력과 비교 후 직접 입력 권장
- 해석은 성향 이해와 대화 팁 위주이며, 운명 판단이 아닙니다
