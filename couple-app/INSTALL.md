# 설치 점검 기록

## 2026-11-22 · v2.1 "다운로드는 되는데 설치가 안 됨"

### 점검 결과

| 항목 | 결과 |
|---|---|
| APK 파일 | 정상 (구조 검증 통과, 5.6MB) |
| 앱 ID | `com.gaegul.couple` |
| 지원 안드로이드 | 7.0 이상 (minSdk 24), targetSdk 36 |
| 서명 | v2 서명, 디버그 키 |
| testOnly | 없음 (일반 설치 가능) |
| **원인 1** | **빌드마다 서명 키가 새로 만들어짐.** 이전 버전 키 `91 29 A8…` ≠ v2.1 키 `EE 2B F8…`. 같은 앱 ID에 다른 서명이면 안드로이드가 덮어쓰기 설치를 거부함 ("기존 패키지와 충돌") |
| **원인 2** | **versionCode가 모든 빌드에서 1로 같았음** |
| 원인 3 (기기) | 갤럭시 One UI 6 이상 **자동 차단**이 켜져 있으면 스토어 밖 APK 설치가 막힘 |

### 조치

- 빌드할 때마다 versionCode가 빌드 번호로 올라가고, versionName이 `package.json`의 버전을 따르도록 워크플로 수정
- 릴리스 페이지와 이 문서에 설치 순서 정리
- 남은 문제: 서명 키 고정. 아래 "서명 키 고정" 참고. 고정하기 전까지는 **업데이트할 때마다 기존 앱을 지우고 설치**해야 함

### 설치 순서 (지금 버전)

1. 기존 앱 → 도구 → 동기화 → **기록 코드 만들기** → 코드를 카톡 나와의 채팅에 붙여넣어 보관
2. 기존 개굴씨 앱 **삭제** (아이콘 길게 누르기 → 삭제)
3. 갤럭시: 설정 → 보안 및 개인정보 보호 → **자동 차단** → 끄기 (설치 후 다시 켜도 됨)
4. APK 열기 → "출처를 알 수 없는 앱" 허용 → 설치. Play 프로텍트 경고가 나오면 세부정보 → 무시하고 설치
5. 새 앱 → 도구 → 동기화 → 코드 붙여넣고 **합치기**

### 서명 키 고정 (한 번만 하면 다음부터 덮어쓰기 업데이트 가능)

`README.md`의 "업데이트해도 기록이 지워지지 않게" 참고. 키를 GitHub 저장소 Secrets에 등록하면 이후 모든 빌드가 같은 키로 서명됨.
