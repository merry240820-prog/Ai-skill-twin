# 토익스피킹 30일 트레이너

모바일 브라우저에서 바로 쓰는 TOEIC Speaking 학습 앱. HTML 파일 하나로 되어 있고,
서버 없이 동작하며 모든 학습 기록은 **사용자 기기 안에만** 저장된다.

## 담고 있는 것

| 탭 | 내용 |
|---|---|
| 홈 | 오늘의 Day, 전체 진행률 · 완주 Day · 녹음 수 · 암기 표현 수, 주차별 진행 막대, 시험 정보 요약 |
| 플랜 | 30일 커리큘럼 107개 과제. 과제 단위 체크, Day 단위 일괄 완료, 시작일 변경 |
| 암기집 | Q1-2 / Q3-4 / Q5-7 / Q8-10 / Q11 파트별 채점 포인트, 템플릿(복사 가능), 필수 표현, 감점 요인 |
| 노트 | 단어·표현 카드 123개(간격 반복: 1 → 2 → 4 → 7 → 14 → 30일), 오답노트(파트·원인 태그·해결 여부) |
| 녹음 | 실전 시간 규칙대로 진행하는 녹음 테스트 + 11문항 모의고사, 재생, 4개 축 자가채점 |

## 녹음 기능

실제 시험의 시간 규칙을 그대로 적용한다.

- Q1-2 지문 읽기 — 준비 45초 / 답변 45초
- Q3-4 사진(장면) 묘사 — 준비 45초 / 답변 30초
- Q5-7 듣고 답하기 — 준비 3초 / 15 · 15 · 30초
- Q8-10 자료 활용 — 자료 읽기 45초, 준비 3초 / 15 · 15 · 30초
- Q11 의견 제시 — 준비 45초 / 답변 60초

준비 시간이 끝나면 신호음과 함께 녹음이 시작되고, 답변 시간이 끝나면 자동으로 저장한 뒤
다음 문항으로 넘어간다. 녹음한 답변은 바로 다시 들으며 발음 · 유창성 · 문법 · 내용을
1~5점으로 채점하고, 그 자리에서 오답노트로 보낼 수 있다.

## 쓰는 법

`index.html`을 휴대폰 브라우저로 연 뒤 홈 화면에 추가하면 앱처럼 쓸 수 있다.

- iPhone Safari: 공유 → 홈 화면에 추가
- Android Chrome: ⋮ → 홈 화면에 추가

## 저장과 백업

| 데이터 | 저장 위치 |
|---|---|
| 진행률 · 단어 암기 단계 · 오답노트 | 브라우저 localStorage |
| 녹음 오디오 | 브라우저 IndexedDB |

어떤 것도 네트워크로 전송되지 않는다. 브라우저 데이터를 지우면 함께 사라지므로,
설정(⚙) → 백업 만들기로 진행 기록을 내보내 둘 것. 녹음 오디오는 용량 때문에 백업에 포함되지 않는다.

## 기술 메모

- 의존성 없음. 외부 요청은 Google Fonts 하나뿐이고, 로드에 실패해도 시스템 폰트로 동작한다.
- 녹음은 `MediaRecorder` + `getUserMedia`. 마이크를 쓸 수 없으면 타이머만으로 계속 연습할 수 있다.
- 라이트/다크 테마 모두 대응하며, 설정에서 고정할 수 있다.
