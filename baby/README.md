# 우리 아기 육아 다이어리 (v1)

마미톡 스타일의 부부용 육아 기록 앱. 설치 없이 브라우저/홈 화면 앱(PWA)으로 사용합니다.

## 기능
- 아기 프로필 (이름·생일·D+일수·개월 수)
- 빠른 기록: 분유 / 모유 / 수면(시작·종료) / 기저귀 / 체온 / 메모 — 기록자(아빠·엄마) 표시
- 날짜별 기록 타임라인, 오늘 요약
- 성장 기록 (체중·키·머리둘레) + 그래프
- 예방접종 · 영유아 건강검진 일정 자동 계산 + 완료 체크 (참고용)
- 배우자와 공유: 기록 내보내기 → 받은 기록 합치기 (중복 없이 병합)

## 배포 (GitHub Pages)
저장소 Settings → Pages → Branch 선택 → 폴더 `/ (root)` → 주소 뒤에 `/baby/` 로 접속.
폰에서 접속 후 "홈 화면에 추가"하면 앱처럼 사용할 수 있어요.

## 데이터
기록은 각자 기기 브라우저(localStorage)에 저장됩니다. 서버로 전송되지 않아요.
