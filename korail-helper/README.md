# 기차표 도우미

매진된 기차표를 구할 때 **언제 무엇을 해야 하는지 챙겨 주는** 모바일 웹앱.
HTML 파일 하나로 되어 있고, 서버 없이 동작하며 모든 기록은 **사용자 기기 안에만** 저장된다.

코레일 서버에는 접속하지 않는다. 조회·예약·예약대기 신청·결제는 코레일톡이나 코레일 홈페이지에서
직접 하고, 이 앱은 그 과정을 기록하고 알려 주는 역할만 한다.
(코레일은 자동화 요청을 `MACRO ERROR`로 차단하고 있고, 약관상 매크로 사용도 금지되어 있다.
`../korail-bot` 참고.)

## 기능

| 화면 | 내용 |
|---|---|
| 여정 | 찾는 표(구간·날짜·시간대·열차·좌석·승객·메모) 저장, 진행 상태 관리, 조건 복사, 코레일 홈페이지 바로가기 |
| 알림 | 모든 여정의 조회 알림 시각표, 캘린더(.ics) 저장, 화면 알림 켜기 |
| 가이드 | 예약대기 → 배정 → 결제 순서, 취소표 잡는 요령 |

### 진행 상태

`찾는 중` → `예약대기 신청` → `좌석 배정` → `결제 완료` (또는 `포기`)

- **찾는 중 / 예약대기 신청**: 여정마다 고른 시각(3일 전 저녁 9시, 전날 아침 8시, 전날 저녁 9시,
  출발 3시간 전, 출발 1시간 전)에 취소표 조회·배정 확인 알림을 만든다.
- **좌석 배정**: 코레일톡에 표시된 결제 기한을 입력하면 남은 시간을 카운트다운으로 보여 주고,
  마감 10분 전에 알린다.

## 알림 받는 법

- **캘린더 저장 (권장)**: 여정 카드나 알림 화면의 버튼으로 `.ics` 파일을 받아 휴대폰 캘린더에 추가하면
  앱을 닫아도 정해진 시각에 알림이 온다.
- **화면 알림**: 브라우저 알림을 허용하면 앱이 열려 있는 동안 알림이 뜬다. 앱을 닫으면 오지 않는다.

## 쓰는 법

`index.html`을 휴대폰 브라우저로 연 뒤 홈 화면에 추가한다.

- iPhone Safari: 공유 → 홈 화면에 추가
- Android Chrome: ⋮ → 홈 화면에 추가

## 저장과 백업

여정은 브라우저 localStorage(`trainHelper.v1`)에 저장된다. 브라우저 데이터를 지우면 사라지므로
설정(⚙) → 백업 파일 만들기로 내보내 둘 것. 외부 요청은 Google Fonts 하나뿐이고, 로드에 실패해도
시스템 폰트로 동작한다.
