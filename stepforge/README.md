# StepForge — 나만의 STEP 편집 3D 프로그램

STEP(.step / .stp) 파일을 열어 3D로 보고, 치수를 재고, 형상을 고친 뒤 다시 STEP으로 저장하는
개인용 CAD 프로그램이다. 솔리드웍스와 같은 B-Rep 정밀 형상(OpenCascade 커널)을 쓰므로
원·원통이 실제 곡면으로 유지되고, 저장한 STEP을 솔리드웍스에서 그대로 열 수 있다.

## 실행

| OS | 방법 |
|---|---|
| Windows | `run_windows.bat` 더블클릭 (Python 3.10 이상 필요, 첫 실행 때 자동 설치) |
| macOS / Linux | `./run.sh` |

실행하면 브라우저가 `http://127.0.0.1:8765` 로 열린다. 서버는 내 PC 안에서만 돌고, 파일은 밖으로 나가지 않는다.

직접 설치하려면:

```bash
pip install -r requirements.txt
python server.py
```

## 기능

| 메뉴 | 기능 |
|---|---|
| 파일 | 새 문서, STEP 열기(끌어다 놓기 가능), STEP 가져오기(현재 문서에 추가), STEP 저장, STL 내보내기 |
| 피처 | 기본 형상(상자·원통·구·원뿔), 면 밀기/당기기, 구멍(지름·깊이·관통, 좌표 지정), 필렛, 챔퍼, 쉘, 면 삭제(구멍·필렛 메우기), 합치기/빼기/교차 |
| 이동/변형 | 이동, 복사, 회전(X/Y/Z), 크기(균일·축별), 대칭, 바디 삭제 |
| 측정/평가 | 측정(길이·지름·반지름·면적·좌표·법선 / 두 요소 사이 최소 거리·dX·dY·dZ·평행 거리·중심 거리·각도), 질량 특성(부피·표면적·질량·무게중심·크기), 단면도 |
| 보기 | 정면·윗면·우측면·후면·아랫면·등각, 전체 보기, 와이어프레임, 모서리 표시, 원근/평행 투영 |
| 공통 | 실행 취소/다시 실행(100단계), 작업 기록, 바디 이름·색상·숨기기, 선택 필터(면/모서리/점) |

## 마우스 · 단축키 (솔리드웍스와 같게)

| 동작 | 조작 |
|---|---|
| 회전 | 가운데 버튼 드래그 (또는 Alt + 왼쪽 드래그) |
| 이동 | Ctrl + 가운데 드래그, 또는 오른쪽 드래그 |
| 확대/축소 | 휠 |
| 선택 / 해제 | 왼쪽 클릭 (다시 클릭하면 해제), Esc 전체 해제 |
| 전체 보기 | F 또는 더블클릭 |
| 측정 | M |
| 선택한 면 삭제 | Delete |
| 실행 취소 / 다시 실행 | Ctrl+Z / Ctrl+Y |
| 저장 / 열기 | Ctrl+S / Ctrl+O |

## 구조

```
stepforge/
├── server.py          로컬 웹 서버(FastAPI) — 화면과 형상 엔진을 잇는다
├── core/
│   ├── geometry.py    형상 엔진: STEP 입출력, 메시, 측정, 피처, 불리언, 변환 (OpenCascade)
│   └── document.py    문서: 바디 목록, 작업 기록, 실행 취소/다시 실행
├── web/               화면: index.html, style.css, app.js (three.js 3D 뷰어)
├── samples/           예제 STEP (bracket.step)
└── tests/             형상 엔진 자동 테스트 (pytest)
```

## 테스트

```bash
pip install pytest
python -m pytest tests
```

## 한계

- 솔리드웍스의 피처 트리(치수를 바꾸면 모델이 다시 계산되는 방식)는 없다. STEP에는 원래 설계 이력이 없으므로
  이 프로그램은 형상을 직접 고치는 "다이렉트 모델링" 방식이다.
- 스케치, 조립품 구속조건, 도면은 아직 없다(개발 계획서의 다음 단계).
- STEP 안의 색상·부품 이름은 아직 읽지 않는다.
